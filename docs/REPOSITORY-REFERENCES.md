## 不应视作缺失仓库文件的路径

| 类别 | 核验结论 |
| --- | --- |
| Markdown 相对链接、题面本地图片 | 目标必须存在于可分发文件集合，包含子目录链接 |
| `tmp/`、`build/`、评测输出、SQLite 与日志 | 运行后生成；文档明确注明，不要求克隆后存在 |
| Python 环境、编译器、系统头文件 | 按 [安装说明](../README.md) 准备的外部依赖 |
| 示例 ZIP、PDF、XLSX、布局 JSON | 用户输入占位名，不是附带样例数据 |
| 题包表中的路径及通配符 | 相对各题目录解释；逐题配置、源码和图片均实际存在 |
| manifest 的 workspace / outputRoot | 原始导出机溯源元数据，加载器不用于定位，保持原样 |
| 已提交验收日志 / 性能报告内的绝对路径 | 当时环境的真实记录，不能作为当前命令或链接执行 |
| 第三方源码中的上游出处、标准库引用 | 来源或安装依赖，不伪装成本仓库文件 |

没有为了消除历史路径而改写题包摘要、验收日志或 manifest。
个人题包和原 VP 数据保留；对应临时调试目录已移入本机回收站。

对行内路径、运行命令与脚本资源路径另行核验并按上表分类。
目录存在于本机但被 Git 忽略，不算作链接通过。
