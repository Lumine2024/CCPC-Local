# Vote 题解

## 批量处理相同偏好值

一次拉票只会把被选中的人改到刚好能确定投票的位置：王小畅改到 $+1$，刘小鹏改到 $-1$。原来偏好值为 $a\le0$ 的人转投王小畅需要 $1-a$ 元；原来 $a\ge0$ 的人转投刘小鹏需要 $a+1$ 元。同一偏好值的一整组人可以一起处理。

用有序映射维护每个现存偏好值的人数，同时维护正、负偏好值的人数。王小畅拉票时，先检查正偏好值人数是否达到 $k$。不足的部分依次从 $0,-1,-2,\ldots$ 的现存组中取人，计费后统一放到 $+1$ 组。刘小鹏对称地从 $0,+1,+2,\ldots$ 取人并放到 $-1$ 组。

取完一整组，就将该组从映射中删去；仅取一部分时，减少该组人数后本次拉票即结束。被移入的组只有 $+1$ 或 $-1$，因此即使候选人交替拉票，反复出现的近零组每条记录也只处理常数次。其他组由到达记录产生，整组被删后不会重新出现，除非又有新的到达记录。因此所有拉票操作合计处理 $O(Q)$ 个组。

## 正确性

对于王小畅，偏好值为 $a\le0$ 的一票花费 $1-a$，该值随 $a$ 增大而减小。因此从最靠近 $0$ 的非己方村民开始改变，恰好是题目指定顺序。将一位村民改到 $+1$ 已能确定投票，再多花钱没有必要。映射操作与逐人过程给出相同的新偏好值和总花费；同一组内先后顺序不影响结果。对刘小鹏的证明完全对称。按记录顺序归纳，映射中的人数和偏好值始终与实际状态一致，所以每次输出正确。

## 复杂度

使用平衡树映射，每组操作 $O(\log Q)$，总时间 $O(Q\log Q)$，空间 $O(Q)$。人数与花费都要使用 $64$ 位整数。
