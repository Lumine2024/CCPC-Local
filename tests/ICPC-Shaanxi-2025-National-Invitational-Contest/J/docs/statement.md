# J. message

有 $n$ 个孩子坐成一圈，座位编号从 $0$ 到 $n-1$。每个孩子有一张数字为 $2$ 或 $3$ 的卡片。若编号为 $i$ 的孩子收到消息，他会将消息传给编号为 $(i+a_i)\bmod n$ 的孩子，其中 $a_i$ 是他卡片上的数字。消息可继续传递，同一孩子也可能再次收到消息。

老师可以先**任意重排孩子的座位**，然后选一个孩子作为最初接收者。问能否让每个孩子最终都收到消息。

## 输入格式

第一行一个整数 $T$，表示测试用例数。每组测试先输入整数 $n$，再输入 $n$ 个整数 $a_0,\ldots,a_{n-1}$，表示孩子原本持有的卡片数字。重排只改变座位，卡片始终跟着其持有者。

保证 $1\le T\le10^5$，$1\le n\le10^5$，$a_i\in\{2,3\}$，且所有测试用例的 $n$ 之和不超过 $10^6$。

## 输出格式

每组测试输出一行 `Yes` 或 `No`。

## 样例

```input1
3
3
2 3 2
4
2 2 2 2
6
3 2 3 2 3 3
```

```output1
Yes
No
Yes
```
