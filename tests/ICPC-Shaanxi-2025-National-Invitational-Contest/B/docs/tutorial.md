# 题解

称元素在当前区间内「必要」，当且仅当它是某个素数最大指数的唯一提供者。若删除它，对应的最小公倍数必然变小。否则，删除它仍保留全部最大指数，因此「全选」与「不选它」是两个不同方案。区间为好区间当且仅当存在不必要元素。

对每个素数维护窗口中 $(指数,下标)$ 的有序集合。仅当最大指数由唯一元素持有时，给该元素一张「必要证书」。维护每个元素的证书数及有证书的元素数 $E$。窗口好当且仅当长度至少为二且 $E<窗口长度$：单元素区间不能选出两个不同的非空下标集合。一次增删素因子只会改变对应素数原持有者和新持有者的证书。

固定左端点后，好区间对右端点单调：原来相同的两种子集同时加入新元素，仍具有相同的最小公倍数。因此双指针寻找每个左端点的第一个好右端点，把其后所有右端点加入答案。先用最小素因子筛分解 $a_i$。每个元素进出窗口至多一次，素因子种类数不超过七，时间 $O(10^6+n\log n\log 10^6)$，空间 $O(10^6+n\log 10^6)$。答案须用 64 位整数。

第二份程序按指数分层，并在每层用队列保存窗口中的下标，利用下标进出顺序单调，实现独立的窗口数据结构。
