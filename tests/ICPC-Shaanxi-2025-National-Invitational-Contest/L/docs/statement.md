# L. clothes

小明有 $n$ 件衣服，第 $i$ 件衣服的保暖值为 $a_i$。他要从中带走若干件，以应对接下来 $m$ 天的天气。每天可以从带走的衣服中任选一个**非空**子集穿着；不同天可以选择不同的子集。

第 $i$ 天给出 $t_i,x_i$：

- 如果 $t_i=1$，当天所穿衣服的保暖值之和必须**至少**为 $x_i$。
- 如果 $t_i=2$，当天所穿衣服的保暖值之和必须**不超过** $x_i$。

求能满足所有天要求的最少携带件数。若不可能，输出 $-1$。

## 输入格式

第一行整数 $n$，表示衣服数。第二行 $n$ 个整数 $a_1,\ldots,a_n$。第三行整数 $m$，表示天数。接下来 $m$ 行，每行两个整数 $t_i,x_i$。

保证 $1\le n\le3$，$1\le a_i\le2\times10^5$，$1\le m\le100$，$t_i\in\{1,2\}$，$1\le x_i\le10^9$。

## 输出格式

输出一个整数，表示最少携带件数；无解时输出 $-1$。

## 样例 1

```input1
3
2 3 5
1
1 10
```

```output1
3
```

## 样例 2

```input2
3
2 3 5
2
1 5
2 2
```

```output2
2
```

## 样例 3

```input3
3
7 11 13
2
1 24
2 7
```

```output3
3
```

## 样例 4

```input4
2
17 19
2
1 16
2 18
```

```output4
1
```

## 样例 5

```input5

```
